# AI Job & Resume Management Platform

A production-oriented MERN application for managing resumes, job opportunities, applications, 
and AI-powered resume insights.

## Tech Stack

### Frontend
- React
- Vite
- Axios
- React Router

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

## Project Structure

- `client` - React frontend
- `server` - Node.js/Express backend
